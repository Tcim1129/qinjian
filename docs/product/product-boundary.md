# 亲健产品定位、边界与阶段 0 功能取舍

版本：2026-07-17 阶段 0 基线。

## 一句话定位

**亲健——面向青年伴侣的 AI 沟通记录与关系修复支持平台。**

它帮助双方把日常摩擦转成可回看记录、沟通前预演和一个可共同验证的小行动；它不是心理治疗、关系裁决或自动监控工具。

## 第一阶段服务对象

- 18 至 30 岁、已建立稳定亲密关系的成年人；
- 存在日常沟通摩擦，但双方仍有改善意愿；
- 愿意使用轻量记录、明确共享边界和共同小行动；
- 可以选择先单人整理，不以邀请伴侣作为使用前提。

## 第一阶段非目标

- 未成年人；
- 严重家暴、胁迫、跟踪、自伤或他伤等需要现实安全处置的场景；
- 临床心理诊断、治疗和医疗建议；
- 法律意见、分手/复合裁决、人格好坏判定；
- 普通朋友、亲子家庭、陌生人匹配和公开社交；
- 自动读取聊天记录、监控伴侣或代替用户发送消息。

遇到高风险线索时，产品应停止普通“增进感情”建议，优先提示暂停冲突、保护人身安全并联系可信支持或专业资源；风险标签不得自动共享给伴侣。

## 产品提供与不提供

| 提供 | 不提供 |
| --- | --- |
| 自主记录和整理 | 心理或人格诊断 |
| 沟通前预演和温和改写建议 | 代替用户发送消息 |
| 双方明确授权后的摘要共享 | 默认共享私密原文 |
| 一个共同小行动及反馈 | 关系好坏、分手或复合结论 |
| 带时间窗和来源的阶段观察 | 神秘且绝对的“关系健康总分” |
| 导出、纠错、撤回授权和删除 | 出售隐私、制造依赖或焦虑付费 |
| 高风险提示与专业转介 | 医疗、法律或紧急救援服务 |

AI 输出必须明确标识为辅助生成，允许用户纠正。任何阶段观察至少说明观察周期、数据覆盖、依据来源、置信程度和纠正入口。

## P0：首轮真实闭环

- 公开首页、完整且明确标注的样例、方法与边界、法律和隐私入口；
- 注册、登录、找回密码、18 岁确认、账号与设备会话；
- 单人模式、双人关系空间、邀请、确认、退出和共享边界；
- 一句话记录、可选情绪、默认私密范围；
- 消息预演，不代发；
- 周期观察和简短周报，不以绝对总分作结论；
- 一个共同任务及双方反馈；
- 时间轴、导出、删除、撤回授权；
- AI 标识、高风险转介、安全审计、埋点、反馈与成本监控。

## P1：P0 稳定后的增强

- 图片和语音记录；
- 里程碑与阶段回顾；
- 异地关系共同活动；
- App 推送、离线草稿和设备级隐私能力；
- 阶段观察的趋势与依据展开；
- 多设备会话管理；
- 专业顾问审查工作流。

## P2：真实验证后再决定

- 课程与关系技巧内容库；
- 会员体系和订阅实验；
- 真实专业咨询转介；
- 多种关系类型；
- 个性化干预策略实验；
- 高校 B2B2C 合作版本。

## 暂停或降级

- 未经验证的关系健康总分和用少量题目确定依恋人格；
- 自动判断分手或继续关系；
- 没有真实服务方与审查流程的专家市场；
- 课程、社群、会员等页面数量型空壳；
- 没有用户控制的自动共享；
- 未经安全审查的长时间 AI 陪伴；
- 真实支付、小程序、App 和生产部署（不属于本阶段授权范围）。

## 阶段 0 退出话术

团队应能在三分钟内一致说明：亲健服务愿意改善沟通的成年青年伴侣，用记录、预演和共同小行动支持真实沟通；默认保护个人原文，AI 只是可纠正的辅助；它不做诊断、裁决、监控、代发或紧急救援。
