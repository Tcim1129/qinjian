# 页面功能说明

本文档按当前 `web-vue3/src/router/index.js` 中的前端路由整理，说明每个页面的用途、主要功能和适用场景。除 `/auth` 外，其余页面需要真实登录或通过样例演示入口进入。

## 进入方式

| 模式 | 入口 | 说明 |
| --- | --- | --- |
| 真实账号 | `/auth` | 注册或登录后进入完整功能，可使用真实接口、上传、报告和个人设置 |
| 样例演示 | `/preview-demo.html?route=/目标路径` | 自动注入样例身份和关系数据，支持离线体验、测试验证与全功能走查 |
| 登录页样例按钮 | `/auth` 页面中的“先体验样例” | 勾选协议后进入样例数据，不需要创建真实账号 |

示例：

```text
http://localhost:3001/preview-demo.html?route=/
http://localhost:3001/preview-demo.html?route=/pair
http://localhost:3001/preview-demo.html?route=/relationship-space/b2222222-2222-4222-8222-222222222222
```

## 页面总表

| 页面 | 路径 | 主要功能 |
| --- | --- | --- |
| 登录与注册 | `/auth` | 提供账号登录、注册、忘记密码、协议确认和样例体验入口。 |
| 首页总览 | `/` | 展示今日记录入口、关系摘要、连续记录、关系趋势、五项状态、今日安排和关系树概览。 |
| 总览目录 | `/discover` | 汇总常用入口，集中跳转到记录、简报、时间轴、关系技巧、双视角、关系管理和扩展功能。 |
| 关系管理 | `/pair` | 创建邀请码、加入预览、处理加入确认、切换关系类型、维护备注和处理断绝关系流程。 |
| 等待加入 | `/pair-waiting` | 展示加入关系后的等待状态，提示对方确认前的下一步操作。 |
| 关系空间列表 | `/relationship-spaces` | 汇总当前用户可进入的关系空间，用于多关系切换、查看关系侧栏和管理入口。 |
| 关系空间详情 | `/relationship-space/:pairId` | 展示指定关系的状态、信号、建议动作、关系树能量和关系管理面板。 |
| 今日记录 | `/checkin` | 支持文字记录、情绪标签、互动信息、图片分析、语音转写和实时整理。 |
| 聊一聊 | `/chat` | 提供智能陪伴会话，承接用户的即时表达、语音草稿和持续对话。 |
| 关系简报 | `/report` | 查看日报、周报、月报、历史简报、趋势和系统生成的建议动作。 |
| 时间轴 | `/timeline` | 回看记录、报告、修复节点和归档摘要，展示原始内容的权限边界。 |
| 双视角 | `/alignment` | 将双方记录整理为共享叙事、我方视角、对方视角、误读风险和桥接动作。 |
| 发前看看 | `/message-simulation` | 对待发送消息进行风险预演，给出对方可能接收到的信息、风险原因和更稳妥改写。 |
| 缓和建议 | `/repair-protocol` | 根据风险等级和近期事件生成分步骤修复建议、禁忌行为和成功信号。 |
| 判断说明 | `/methodology` | 解释系统如何理解风险、建议、干预剧本和当前判断依据。 |
| 我的 | `/profile` | 管理个人资料、偏好入口和与账号相关的个人信息。 |
| 隐私与安全 | `/privacy-security` | 管理同步策略、辅助整理开关、隐私审计、上传访问状态和删除申请。 |
| 关系纪念日 | `/milestones` | 记录重要日期，生成阶段回顾，用于关系节点留存。 |
| 异地关系 | `/longdistance` | 提供异地陪伴活动、健康指数和异地场景下的维系建议。 |
| 关系体检 | `/health-test` | 通过固定题包评估关系状态，形成分数和趋势参考。 |
| 依恋类型 | `/attachment-test` | 识别依恋风格，给出关系互动中的理解和成长建议。 |
| 关系技巧 | `/community` | 展示社群提示、沟通建议和可复用的关系技巧内容。 |
| 今日任务 | `/challenges` | 展示系统任务和手动任务，支持完成反馈和今日行动安排。 |
| 课程 | `/courses` | 展示沟通课程入口，承接延展学习场景。 |
| 咨询 | `/experts` | 展示一对一咨询梳理入口，用于更深度的人工支持转介。 |
| 会员 | `/membership` | 展示会员权益和服务方案，承接商业化扩展入口。 |

## 典型业务流程执行顺序

| 顺序 | 页面 | 业务重点 |
| --- | --- | --- |
| 1 | `/auth` 或样例入口 | 说明真实账号和样例演示两种进入方式。 |
| 2 | `/` | 用首页说明当前关系状态、今日记录入口和主要导航。 |
| 3 | `/pair` | 展示关系创建、加入预览和协作确认机制。 |
| 4 | `/relationship-space/:pairId` | 说明关系空间如何汇总状态、信号和行动建议。 |
| 5 | `/checkin` | 展示文字、图片、语音输入以及隐私预检。 |
| 6 | `/report`、`/alignment` | 说明记录如何变成简报和双视角理解。 |
| 7 | `/message-simulation`、`/repair-protocol` | 展示沟通前预演和风险升高后的修复动作。 |
| 8 | `/challenges`、`/timeline` | 说明建议如何落成任务，并在时间轴中回看。 |
| 9 | `/privacy-security` | 收束到隐私治理、审计和删除申请。 |

## 页面边界

- 样例演示模式不会写入真实账号，也不代表真实用户数据。
- 实时语音需要登录真实账号，体验样例暂不提供。
- `/relationship-space/:pairId` 需要有效关系 ID；样例数据可使用 `b2222222-2222-4222-8222-222222222222`。
- 系统输出用于关系记录、整理和沟通支持，不替代医疗、法律或正式心理治疗建议。
