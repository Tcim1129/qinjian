## 当前结论

- 视觉主线：`qinjian-ui-preview`。
- 功能对照：`web-vue3`。
- 真实业务真值：FastAPI 路由及两端正式 API 适配层；任何 fixture、静态页面和截图均不是业务真值。
- 样例真值：新版仅公开 `/sample` 的静态样例；旧版 `demo-mode` / `src/demo/fixtures.js` 仅用于演示和测试。
- 当前不可删除项：两套前端全部代码、旧版独立等待/详情状态、两端测试。
- 当前不可宣称项：专业诊断、关系裁决、合规完成、真实专家供给、真实支付、真实用户留存。

## 自动覆盖检查

执行：

```powershell
python scripts/check_feature_matrix.py
```

脚本读取两套路由，报告矩阵中遗漏的主路由与别名；通过时输出 `matrix complete`。它只证明路由被记录，不证明功能、权限或视觉已完成。
